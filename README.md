##Overview

This project focuses on the design and control of a 2-degree-of-freedom (2-DOF) shaking table for seismic simulation. 
The objective is to replicate real earthquake motions and test structural responses using both classical controllers and Model Reference Adaptive Control (MRAC).

##Features

2-DOF shaking table mechanical and dynamic modeling

Seismic motion simulation for civil engineering applications

Control strategies implemented: 1. Classical PID/PIV controllers  2.MRAC for adaptive performance under uncertainties

Comparison of tracking performance, stability, and robustness

##Implementation

Implemented in MATLAB/Simulink

Includes:

System parameter identification

Dynamic modeling of 2-DOF table

Controller design and tuning

Closed-loop simulations under earthquake-like disturbances
